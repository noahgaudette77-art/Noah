# Phase 4 captures: the title, the arcade hall, the menus and the three quieter rooms

Made by `tools/scenarios/menus.js` (`node tools/capture.js tools/scenarios/menus.js --out docs/combat-pass/menus
--dpr 2`, served, every asset loaded; `PART=title,hub,menus,memory,exam,guide` makes only those parts) on a 390 x 844
phone screen at twice its density. Stills are the whole screen; strips are frames side by side, left to right. The
player is set some way in (nine trophies, five bosses beaten, a best exam of 72%) so earned and unearned things both
show. Everything but the title was made again after the review's fix round.
